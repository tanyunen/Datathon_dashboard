More participants → more transactions with path gaps

Gap rate = percentage of transactions flagged N.
N = an incomplete observed path; Y = a complete observed path.
For each participant count: N ÷ (Y + N) × 100%.

CANDIDATE RULE · THE DASHED LINE IN THE CHART
P(N | k) = 1 − 0.95k − 1

k = number of participants; k − 1 = number of connecting segments.
If each segment independently has a 5% chance of an observation gap, this formula gives the chance of at least one gap in the path.

The observed curve closely follows this pattern. This is a candidate explanation; independence and the exact mechanism remain unverified.

How we checked

Use all 10 million rows, grouped by exact PARTICIPANT_COUNT. Y denotes a continuous, observable BIC path. N denotes a gap or placeholder. Independent ordering and beneficiary BICs define directional country corridors, including domestic pairs.

No rows failed the supplied validity checks. Path-length interpretations assume participant count includes hidden nodes.

What this means for bank-network analysis

Report full-path coverage alongside intermediary rankings. Retaining only Y changes the participant-count distribution and reduces representation of longer routes.
